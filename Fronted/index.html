QUICK REFERENCE
Knowledge Base

                
Common build issues and a first troubleshooting step.

                
                

                    
JAVA
Class not found
Check the class name, package, classpath, and whether compilation completed successfully.

                    
DEPENDENCIES
Package not found
Verify the dependency name and version, repository access, and project configuration.

                    
DOCKER
Image build failed
Review the Dockerfile instruction and the first error in the build output.

                    
JENKINS
Pipeline failed
Open the failed stage's console output and identify the earliest meaningful error.

                    
GIT
Checkout failed
Check repository URL, branch name, credentials, and network access.

                    
PYTHON
Module not found
Confirm the active environment and install the required package in that environment.
